## 🏟️ 3D Визуализация Стадиона - Новые Функции

## Что нового

### 1. 3D Трибуны с высотой рядов
Теперь каждый ряд поднимается выше предыдущего, создавая реалистичный вид трибун стадиона:
- Каждый ряд автоматически поднимается на 30 пикселей
- Базовая высота трибун: 200 пикселей
- Улучшенная перспективная проекция
- Эффект глубины с затемнением дальних рядов
- Свечение активных мест

### 2. Демонстрация на 3 телефонах 📱
Новая вкладка "Демо телефонов" позволяет:
- Симулировать работу перформанса на 3 виртуальных телефонах
- Назначить каждому телефону свой сектор
- Автоматическое получение цветов для выбранных секторов
- Кнопка "Тест" для симуляции мигания
- Реалистичный дизайн iPhone с вырезом

### 3. Интерактивность с секторами
- Кликайте на места в 3D-виде для выбора сектора
- Информационная панель с детальной статистикой по сектору:
  - Название трибуны
  - Общее количество мест
  - Количество активных мест
  - Процент участия

## Как использовать

### Основной вид стадиона
1. Откройте вкладку "🏟️ Вид стадиона"
2. Используйте слайдеры для изменения угла обзора и высоты камеры

4. Используйте кнопки "Север", "Восток", "Юг", "Запад" для быстрого переключения

2. Выберите сектор для каждого из 3 телефонов
3. Нажмите "Сгенерировать перформанс" в боковой панели
4. Телефоны автоматически получат цвета своих мест
5. Нажмите "Тест" на любом телефоне для симуляции мигания

## 🎮 Интерактивное управление 3D-стадионом

## ✨ Новые контролы (как в Google Maps)

### Основное управление

**🖱️ Перетаскивание мышью**
- Зажмите левую кнопку мыши и тяните → вращение вокруг стадиона
- Курсор меняется на "grab" / "grabbing"
- Плавное вращение на 360°

**🔍 Колесико мыши**
- Прокрутка вверх → приближение (zoom in)
- Прокрутка вниз → отдаление (zoom out)
- Диапазон зума: 0.3x - 3.0x
- Плавное масштабирование

**⬆️ Shift + перетаскивание**
- Зажмите Shift + левую кнопку мыши
- Тяните вверх → камера поднимается
- Тяните вниз → камера опускается
- Диапазон высоты: 0% - 100%

**👆 Двойной клик**
- Двойной клик по месту → фокус на сектор
- Открывается информационная панель с деталями
- Показывает трибуну, количество мест, участие

### Быстрые пресеты

Кнопки для мгновенного перехода к стандартным видам:

- **Север** - вид с севера (0°, высота 20%, зум 1x)
- **Восток** - вид с востока (90°, высота 20%, зум 1x)
- **Юг** - вид с юга (180°, высота 20%, зум 1x)
- **Запад** - вид с запада (270°, высота 20%, зум 1x)
- **Обзор** - общий вид (0°, высота 50%, зум 1.5x)

### Индикаторы состояния

В верхней части экрана отображаются текущие параметры:
- **Угол**: текущий угол обзора (0-360°)
- **Высота**: высота камеры (0-100%)
- **Зум**: текущий уровень приближения (0.3x-3.0x)

## 🔧 Технические детали

### Реализация

**Обработчики событий:**
```javascript
- onMouseDown → начало перетаскивания
- onMouseMove → обновление угла/высоты
- onMouseUp → завершение перетаскивания
- onWheel → изменение зума
- onClick → выбор сектора
- onDoubleClick → фокус на сектор
```

**Формулы:**
```javascript
// Вращение
angleDelta = deltaX * 0.5
viewAngle = (viewAngle + angleDelta) % 360

// Высота камеры
heightDelta = -deltaY * 0.001
viewHeight = clamp(viewHeight + heightDelta, 0, 1)

// Зум
zoomDelta = -wheelDelta * 0.001
zoom = clamp(zoom + zoomDelta, 0.3, 3.0)

// Проекция с зумом
cameraDistance = 2500 / zoom
fov = 1000 * zoom
```

### Оптимизация

- Используется `requestAnimationFrame` для плавной анимации
- Обработчики событий добавляются/удаляются через `useEffect`
- Курсор меняется динамически (`grab` / `grabbing`)
- Предотвращение стандартного поведения колесика (`preventDefault`)

## 🎥 Фиксированная камера в центре стадиона

## ✨ Обновленная система управления

### Концепция
Камера теперь **всегда находится в центре стадиона** на фиксированной высоте. Вы не перемещаетесь - вы вращаете камеру вокруг себя, как будто стоите на месте и смотрите по сторонам.

### Управление

**🖱️ Перетаскивание мышью**
- Вращение камеры вокруг вертикальной оси (0-360°)
- Вы стоите на месте, поворачиваете голову влево/вправо
- Плавное круговое вращение

**🔍 Колесико мыши**
- Приближение/отдаление (зум 0.3x - 3.0x)
- Как будто смотрите в бинокль

**⬆️ Shift + перетаскивание**
- Наклон камеры вверх/вниз
- Смотрите на верхние или нижние ряды трибун
- Диапазон наклона: -30° до +30°

**👆 Двойной клик**
- Фокус на выбранный сектор
- Открывает детальную информацию

## 🎨 Улучшенная визуализация

### Обозначения секторов
- Каждый сектор имеет **цветную подсветку** в зависимости от трибуны
- Название сектора отображается в центре
- Выбранный сектор подсвечивается ярче

### Цвета трибун
- **Трибуна A** - красный оттенок
- **Трибуна B** - зеленый оттенок
- **Трибуна C** - синий оттенок
- **Трибуна D** - желтый оттенок

### Улучшенная видимость мест
- Увеличенный размер точек (базовый радиус 2.5px)
- Обводка для активных мест
- Усиленное свечение цветных телефонов
- Более заметные неактивные места (серые)

### Легенда
В левом нижнем углу отображается легенда с цветами всех трибун для удобной навигации.

## 🎯 Примеры использования

### Обзор всего стадиона

2. Медленно вращайте камеру мышью
3. Используйте зум для детального просмотра

### Просмотр конкретной трибуны
1. Нажмите кнопку нужной стороны (Север/Юг/Восток/Запад)
2. Используйте Shift + перетаскивание для наклона
3. Двойной клик на сектор для деталей

### Сравнение секторов
1. Поверните камеру к первому сектору

3. Поверните к другому сектору
4. Сравните визуально

## Пиксельный перформанс - Каждый телефон = пиксель

## Концепция

Система декомпозирует изображение на цветные пиксели, где каждый телефон болельщика на трибуне становится одним пикселем общей картины.

## Новый функционал

### 1. Вид с поля (Field View)

**Что это:**
- 3D проекция трибун с точки зрения человека, стоящего на поле
- Показывает, как перформанс выглядит для игроков и зрителей на поле
- Интерактивное управление углом обзора и высотой камеры

**Как использовать:**
1. Выберите режим "Изображения"
2. Переключитесь на "Вид с поля"
3. Сгенерируйте перформанс
4. Используйте слайдеры для изменения угла обзора (0-360°) и высоты камеры
5. Кнопки быстрого доступа: север, восток, юг, запад

**Управление:**
- Угол обзора: поворот камеры вокруг центра поля
- Высота камеры: от уровня поля (0%) до вида сверху (100%)

### 2. Загрузка изображений

**Предустановленные изображения:**
- Конь ЦСКА (силуэт)
- Логотип ЦСКА
- Российский флаг
- Красная звезда
- Текст "ЦСКА"
- Текст "ВПЕРЕД"
- Цифры 0-9

**Загрузка своих изображений:**
1. В разделе "Изображение" найдите поле "Загрузить своё изображение"
2. Нажмите "Выберите файл"
3. Выберите изображение (PNG, JPG, JPEG)
4. Изображение автоматически добавится в библиотеку
5. Можно сразу использовать для генерации

**API endpoint:**
```
POST /api/images/upload
Content-Type: multipart/form-data

file: <image file>
name: <optional custom name>
```

## Технические детали

### Декомпозиция изображения

1. Изображение масштабируется под размеры арены (10495 × 8086 px)
2. Каждое место на трибуне получает координаты (x, y)
3. Цвет пикселя изображения в точке (x, y) присваивается этому месту
4. Телефон болельщика светится этим цветом

### 3D проекция

**Алгоритм:**
- Камера в центре поля (5247, 4043)
- Высота камеры регулируется (0-2000 px)
- Перспективная проекция с FOV = 800
- Сортировка по глубине (дальние объекты рисуются первыми)

**Координаты:**
- X, Y: координаты места на плане арены
- Z: высота трибун (фиксированная = 500 px)

## Использование

### Для администратора перформанса:

1. Загрузите или выберите изображение
2. Настройте параметры (масштаб, поворот, яркость)
3. Выберите трибуну или всю арену
4. Установите процент заполнения мест
5. Сгенерируйте перформанс
6. Переключитесь на "Вид с поля" для проверки
7. Измените угол обзора, чтобы увидеть с разных сторон

### Для болельщиков:

Каждый болельщик получает на свой телефон:
- Уникальный цвет (RGB)
- Инструкцию держать телефон экраном к полю
- Синхронизацию по времени

# Бизнес-обоснование проекта ЦСКА Performance Generator

> **Примечание (v1.0.0).** В документе описана целевая концепция проекта. Генерация изображений через OpenAI/DALL-E в коде v1.0.0 **не реализована**: сейчас работают режим готовых изображений (библиотека + загрузка) и режим сценариев фонариков. Цифры экономии времени и денег — оценки авторов, а не измерения.


## Executive Summary

AI-сервис для автоматической генерации визуальных перформансов на трибунах ВЭБ Арены, который позволяет за минуты создавать эффектные шоу вместо часов ручной работы.

## Проблема

### Текущая ситуация

1. **Долгая подготовка**: Создание перформанса занимает 3-5 дней
2. **Ручная работа**: Дизайнеры вручную адаптируют изображения под геометрию трибун
3. **Сложность тестирования**: Нет возможности быстро проверить, как будет выглядеть результат
4. **Ограниченный креатив**: Из-за трудоемкости делается 2-3 перформанса за сезон
5. **Высокая стоимость**: Каждый перформанс требует работы дизайнера и координатора

### Боли клиента (ПФК ЦСКА)

- Невозможность быстро реагировать на инфоповоды (победа, юбилей, праздник)
- Ограниченное вовлечение болельщиков
- Отсутствие wow-эффекта на каждом матче
- Сложность координации с болельщиками

## Решение

### Что делает сервис

**ЦСКА Performance Generator** - это веб-платформа, которая:

1. Принимает текстовое описание перформанса
2. Генерирует изображение через AI (DALL-E 3)
3. Автоматически адаптирует под пиксельную сетку трибун
4. Создает анимации и эффекты (волна, вспышки, пульсация)
5. Показывает превью на схеме арены
6. Экспортирует сценарий для показа на телефонах болельщиков

### Ключевые преимущества

✅ **Скорость**: От идеи до готового перформанса за 5-10 минут  
✅ **Простота**: Не нужны навыки дизайна - достаточно описать идею  
✅ **Гибкость**: Можно создавать уникальный перформанс под каждый матч  
✅ **Креативность**: AI генерирует неожиданные визуальные решения  
✅ **Масштабируемость**: Работает для всей арены или отдельных трибун  

## Целевая аудитория

### Внутри клуба

1. **Матчдэй-менеджеры** - организация шоу на стадионе
2. **Маркетинг** - промо-активации и спонсорский контент
3. **Fan Engagement** - вовлечение болельщиков
4. **Медиа-команда** - контент для соцсетей

#### 2. Особые события
- Юбилеи игроков
- Праздники (Новый год, День победы)

#### 3. Спонсорские активации
- Логотипы партнеров
- Промо-кампании
- Интерактивные игры

#### 4. Реакция на события
- Гол команды - вспышки и салют
- Победа - анимация трофея
- Рекорд игрока - персональное поздравление

## Технологическая реализация

### Архитектура

```
Frontend (React) → Backend (FastAPI) → AI (OpenAI DALL-E 3)
                         ↓
                  Image Processing
                         ↓
                  Seats Mapping (29,071 мест)
                         ↓
                  Preview & Export
```

### Технологический стек

- **Backend**: Python, FastAPI, Pillow, NumPy
- **Frontend**: React, Axios
- **AI**: OpenAI DALL-E 3
- **Data**: JSON с координатами 29,071 мест ВЭБ Арены

### Инновации

1. **Умная адаптация**: Автоматический ресайз под геометрию трибун
2. **Битые пиксели**: Учет того, что не все болельщики участвуют
3. **Оптимизация промптов**: AI улучшает описание для стадионного показа
4. **Эффекты**: Волны, вспышки, пульсация, каскады по секторам

## Риски и ограничения

### Технические риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Качество AI-генерации | Средняя | Высокое | Ручная доработка, библиотека шаблонов |
| Не все болельщики участвуют | Высокая | Среднее | Алгоритм "битых пикселей", fill_rate 70-80% |
| Разные экраны телефонов | Высокая | Низкое | Калибровка яркости, простые цвета |
| Задержка генерации (30-60 сек) | Высокая | Низкое | Предварительная подготовка, кэширование |

### Организационные риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Сопротивление персонала | Низкая | Среднее | Обучение, демонстрация преимуществ |
| Интеграция с текущими системами | Средняя | Высокое | API-first подход, модульность |
| Координация с болельщиками | Высокая | Высокое | Мобильное приложение, инструкции |

### Решения

1. **Библиотека шаблонов**: Готовые проверенные перформансы
2. **Гибридный подход**: AI + ручная доработка при необходимости
3. **Тестирование**: Пилот на 2-3 матчах перед полным запуском
4. **Обучение**: Тренинги для матчдэй-команды

# ЦСКА Performance Generator - Презентация проекта

> **Примечание (v1.0.0).** В документе описана целевая концепция проекта. Генерация изображений через OpenAI/DALL-E в коде v1.0.0 **не реализована**: сейчас работают режим готовых изображений (библиотека + загрузка) и режим сценариев фонариков. Цифры экономии времени и денег — оценки авторов, а не измерения.


## 🎯 Проблема

Подготовка визуальных перформансов для трибун стадиона - это:
- ⏰ **3-5 дней** ручной работы
- 💰 **50,000₽** за один перформанс
- 🎨 Требует профессионального дизайнера
- 🐌 Невозможно быстро реагировать на события

## 💡 Решение

**AI-сервис для генерации перформансов за 5 минут**

### Как это работает?

```
1. Введите описание → "логотип ЦСКА с красно-синими цветами"
2. AI генерирует изображение → DALL-E 3
3. Адаптация под трибуны → 29,071 место ВЭБ Арены
4. Превью и экспорт → Готово к показу!
```

## 🚀 Возможности MVP

### ✅ Реализовано

1. **Генерация изображений**
   - Текстовый промпт → AI-изображение
   - Автоматическая оптимизация для стадиона
   - Высокий контраст и яркие цвета

2. **Адаптация под трибуны**
   - Маппинг на 29,071 место
   - Учет геометрии ВЭБ Арены
   - Симуляция "битых пикселей" (не все участвуют)

3. **Анимации и эффекты**
   - 🌊 Волна
   - ⚡ Вспышки
   - 💓 Пульсация

4. **Веб-интерфейс**
   - Простая админка
   - Предпросмотр в реальном времени
   - Настройка параметров

5. **Гибкость**
   - Вся арена или отдельные трибуны (A, C, K, S)
   - Настройка заполнения (50-100%)
   - Экспорт результатов

## 💻 Демонстрация

### Запуск локально

```bash
# Backend
cd backend
pip install -r requirements.txt
python main.py

# Frontend
cd frontend
npm install
npm start
```

### API

```bash
# Генерация изображения
curl -X POST http://localhost:8000/api/generate/image \
  -H "Content-Type: application/json" \
  -d '{"prompt": "CSKA logo", "fill_rate": 0.8}'

# Список трибун
curl http://localhost:8000/api/generate/tribunes

# Информация об арене
curl http://localhost:8000/api/preview/arena-info
```

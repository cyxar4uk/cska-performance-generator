# Changelog

## v1.0.0 — 2026-10-25

Первый открытый релиз.

### Возможности
- Backend на FastAPI: режим готовых изображений (библиотека, загрузка своих, масштаб/поворот/яркость/контраст, доля участвующих мест) и режим сценариев фонариков (волна, вспышки, градиент, пульсация, каскад, бегущий текст, огонь, радуга, звёзды, сердце, счёт, комбинированные).
- Маппинг изображения на координаты мест трибун и PNG-превью.
- Frontend на React: 3D-вид стадиона «с поля» (фиксированная камера в центре, вращение мышью, зум, выбор секторов, статистика) и демо на трёх виртуальных телефонах.
- Генератор синтетической схемы мест `scripts/generate_sample_seats.py` для запуска без реальных данных арены.
- Тесты (pytest) и GitHub Actions CI (backend + сборка frontend).

### Исправлено при подготовке релиза
- `/api/images/generate` падал при сериализации цветов (`numpy.uint8`) — значения приводятся к `int`.
- Прокси CRA указывал на порт 8001, backend по умолчанию слушает 8000; адрес настраивается через `BACKEND_URL`.
- Путь к файлу мест больше не зависит от текущей директории (`SEATS_FILE` → `data/seats.json` → `data/seats.sample.json`).

### Известные ограничения
- Генерация изображений через OpenAI/DALL-E, упомянутая в исходной документации, не реализована; `OPENAI_API_KEY` не используется.
- Реальная схема арены (`data/seats.json`) не входит в репозиторий.
- Frontend пока не использует эндпоинты `/api/flashlights/*` (доступны через API / Swagger).

### Документация
- Многочисленные корневые MD-файлы сведены в `docs/`; статусные отчёты и чек-листы хакатона в релиз не вошли.
